**THEORY**

Data visualization is the process of representing data in graphical or pictorial form so that patterns, trends, and relationships can be understood easily. Instead of reading large tables of numbers, visual charts help users quickly interpret information. In data science and analytics, visualization plays an important role in analyzing datasets and communicating results effectively.

In Python, data visualization is commonly performed using libraries such as Matplotlib and Seaborn. These libraries provide powerful tools for creating different types of charts like line graphs, bar charts, histograms, scatter plots, and pie charts.

Matplotlib is one of the most widely used visualization libraries in Python. It allows users to create static, animated, and interactive graphs. The pyplot module of Matplotlib provides functions similar to MATLAB commands, making it easier to generate plots with simple code. Using Matplotlib, we can customize graphs by adding titles, labels, legends, colors, and grids to make the visualization clearer and more informative.

Seaborn is another Python visualization library built on top of Matplotlib. It provides a higher-level interface for creating attractive and informative statistical graphics. Seaborn simplifies the process of plotting complex datasets and automatically applies better visual styles and color palettes.

Charts are used to visually encode data. Visual encoding refers to representing data values using visual elements such as position, color, size, shape, and length. For example, in a bar chart, the height of the bars represents the value of data, while in a line chart, the position of points connected by lines shows the trend of the data over time.

A line chart is used to show trends or changes in data over a period of time. It is commonly used for representing continuous data such as temperature changes, sales growth, or marks obtained over several tests.

A bar chart is used to compare different categories of data. Each category is represented by a rectangular bar, and the height or length of the bar indicates the value of the data.

In this experiment, different charts are created using Python visualization libraries to represent data such as study hours, marks, and attendance. These charts help in understanding patterns in the dataset and demonstrate how graphical representation can make data analysis easier and more meaningful.

Through this experiment, students learn how to use Python tools for creating visual representations of data and understand the importance of charts in data analysis and decision-making.

**FUNCTIONS USED**

1. plt.plot()

This function is used to create a line chart. It connects data points with a line to show trends or changes in data over time.

2. plt.bar()

This function is used to create a bar chart. It represents categorical data with rectangular bars whose height corresponds to the value of the data.

3. plt.title()

This function is used to add a title to the chart, helping the viewer understand what the graph represents.

4. plt.xlabel()

This function labels the x-axis of the chart, indicating what the horizontal axis represents.

5. plt.ylabel()

This function labels the y-axis of the chart, indicating what the vertical axis represents.

6. plt.legend()

This function displays a legend on the graph. It helps identify different datasets or lines in the chart.

7. plt.show()

This function is used to display the chart on the screen after it has been created.

8. sns.barplot()

This function from the Seaborn library is used to create a visually enhanced bar chart with statistical information.

9. sns.set_style()

This function is used to set the overall style of the plots, making the charts more visually appealing.

10. plt.figure()

This function is used to create a new figure or adjust the size of the graph window before plotting.
